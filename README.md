# CloudDrive — AWS S3 Storage Simulator

## Project Overview
"CloudDrive" is an interactive simulation of Amazon S3 object storage. It is built as a complete, polished, functional web application designed for academic demonstration. The application allows users to simulate the core functionalities of Amazon S3 without requiring actual AWS credentials, using the browser's IndexedDB for robust local persistence.

## Objective
The objective of this project is to simulate Amazon S3 and extend it with a meaningful enhancement: a dynamic Storage Analytics Dashboard. 

## AWS Service
**Amazon S3 (Simple Storage Service)**

## Core Functionality
- **Bucket Management:** Create, view, open, and delete buckets.
- **Object Storage:** Upload real files as objects (persisted in IndexedDB).
- **Object Management:** View object metadata, download objects, and delete objects.
- **Search & Filter:** Find objects quickly using search and file type filters.
- **Bucket Protection:** Buckets cannot be deleted unless they are empty.

## Enhancement
**Storage Analytics Dashboard:** 
A dedicated analytics page dynamically calculates and visualizes simulated storage usage, breaking it down by file type and bucket. It also lists the largest objects and provides a storage usage warning if a simulated threshold (e.g., 1GB) is exceeded.

## Technology Stack
- **Frontend Framework:** React 18, TypeScript, Vite
- **Styling:** Tailwind CSS v4
- **Icons:** Lucide React
- **Charts:** Recharts
- **Storage:** IndexedDB (via `idb` library)
- **Routing:** React Router DOM

## Architecture
```
React UI Components
        ↓
Service Layer (Repositories)
        ↓
   IndexedDB API
        ↓
Stored Buckets and Objects (Blobs)
```

## How S3 Concepts Are Simulated
- **Bucket:** Represented by an IndexedDB record containing metadata (name, region, totals).
- **Object:** Represented by an IndexedDB record containing a stored File/Blob and metadata.
- **Object Key:** Used as the unique identifier/name for the object.
- **Storage:** Blob sizes are dynamically aggregated to simulate storage consumption.
- **Region:** A simulated metadata tag assigned during bucket creation.

## Installation

```bash
# Install dependencies
npm install

# Start the development server
npm run dev
```

## Build

```bash
# Build for production
npm run build
```

## Deployment
The project is ready to be deployed as a static web application to platforms like GitHub Pages, Vercel, or Netlify. The `dist` folder generated by `npm run build` contains the compiled static assets.

## Limitations
**This application is an educational simulation and does not directly connect to Amazon S3.** All data is stored locally in your browser's IndexedDB and is not synchronized to any cloud service.
